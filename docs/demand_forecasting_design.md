# Demand Forecasting Module

## Objective
Predict future product demand using historical sales data.

## Input Data
- Date
- Product ID
- Product Name
- Quantity Sold
- Sales Revenue
- Inventory Level

## Forecasting Pipeline

1. Data Loading
2. Data Cleaning
3. Time Series Preparation
4. Trend Analysis
5. Prophet Model
6. Forecast Generation
7. Forecast Evaluation

## Evaluation Metrics

- MAPE
- RMSE
- MAE

## Outputs

- forecast_output.csv
- forecast_metrics.csv
